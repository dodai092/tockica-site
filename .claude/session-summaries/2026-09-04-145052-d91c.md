# Session summary — 2026-09-04

**Skills used:** /grill-with-docs, /karpathy, /session-summary

## What was done

Turned this fresh AstroWind fork into a reusable, hardened template for Dodai client
websites. Started by grilling the intended workflow into decisions and docs
(`CONTEXT.md`, `SETUP.md`, ADR 0001), then implemented a four-phase hardening plan under
the karpathy guidelines, verifying `npm run build` + `npm run check` + the new CI gates
after each phase. Nothing is committed yet — 59 changed paths sit on `main`.

Key decisions (full detail in `CONTEXT.md` / `docs/adr/0001`): GitHub template repo (not
fork); `src/components/widgets/` is a read-only "parts bin", per-client work goes in
`src/components/client/`; template core is never edited per build; blog off by default;
Netlify is the default deploy target; brand values live only in `src/brand.ts`, schema in
`src/schema.ts`; Decap CMS removed; bilingual out of scope. Open decision left for Antun:
analytics vendor (recommendation = Plausible/Fathom to dodge an EU cookie banner).
