## Notes

- **Push is Antun's call.** `main` is 37 ahead of `origin/main`. Phase 1 (tokens), Gap B/C,
  Phase 2 are all in that gap. House pattern: FF-merge local, push separately.
- **After pulling `main` in another checkout, run `npm install`** — `astro-og-canvas` +
  `canvaskit-wasm` are new deps. `npm run check` shows 3 phantom errors until you do.
- **Deferrals recorded in ADR 0005** (none block anything): OG card has no logo (needs a
  `brand.logo.ogPath` string field); OG card font is the `astro-og-canvas` default fetched
  from `api.fontsource.org` at build (same host class as the existing Astro Fonts API, so
  not a new failure mode); blog-post OG images deferred (blog off by default, needs a core
  `[...blog]` change); `src/utils/images.ts` `OG_HEIGHT=626` disagrees with the 1200x630
  rule (no live mismatch, every page passes explicit 630); `lighthouserc.cjs`
  `staticDistDir` only autodiscovers 5 URLs so `/pricing` `/services` `/thank-you` are not
  LHCI-gate-covered (pre-existing template CI gap, manually verified 100/100/100).
- **Loader deviation from spec:** the spec (Part 1) described a `glob` loader over
  `src/content/<name>/` directories; the implementation uses `file()` over one YAML per
  collection (simpler to empty). Noted in ADR 0005.
- **Rulings made during the run** (all were in the now-deleted SDD ledger): `.prettierignore`
  for planning docs; two controller-direct verifications instead of agent re-reviews (a

  intentionally exceeded its file set to fix an LHCI gate that was already red on the base
  branch (`lighthouserc.cjs` matrix + drop `public/__forms.html`).
- **`npm run test:lhci` was red on `main` before this session** (`/dev/*` noindex pages);
  it is green now.
