# Golden Screenshot Tooling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a committed Playwright screenshot tool (`scripts/screenshot.mjs`) that
captures every page of the built site at three viewports and in both color schemes,
plus a `--check` mode that diffs against a committed baseline, so a later `golden`
branch (sub-project C) can be regression-tested against a real build.

**Architecture:** A single Node ESM script drives Playwright's Chromium against an
`astro preview` server it spawns itself. Write mode saves PNGs to `golden-baselines/`;
check mode compares the same captures against those PNGs with `pixelmatch`, writing
any diffs to a gitignored `golden-baselines-diff/` and exiting non-zero on mismatch.
Determinism comes from disabling CSS animations/transitions and forcing every
`intersect`-gated element to its settled state before each capture.

**Tech Stack:** Node (native `fetch`, `child_process`, `fs/promises`), Playwright
(Chromium only), `pixelmatch` + `pngjs` for pixel diffing, Astro's own `astro preview`
as the static server (correct routing/config for free, no server code to maintain).

**Spec:** `docs/superpowers/specs/2026-09-04-golden-branch-and-vinalia-build-design.md`,
sub-project A.

## Task 3: Write `scripts/screenshot.mjs` (write mode)

**Files:**

- Create: `scripts/screenshot.mjs`

**Interfaces:**

- Consumes: `golden-baselines/routes.json` (Task 2), `playwright` (Task 1), a built
  `./dist/` (produced by `npm run build`, not part of this task).
- Produces: `golden-baselines/<slug>/<scheme>-<viewport>.png` files, one per
  `route × {light, dark} × {mobile, tablet, desktop}`. `slugForRoute('/')` returns
  `'home'`; any other route has its leading/trailing slashes stripped and internal
  slashes replaced with `-` (e.g. `/usluge/foo` -> `usluge-foo`) — later tasks and any
  future route additions rely on this exact naming.

- [ ] **Step 1: Write the script**

Create `scripts/screenshot.mjs`:

```js
#!/usr/bin/env node
// Screenshot every route in golden-baselines/routes.json at three viewports and in
// both color schemes, using a built ./dist (run `npm run build` first).
//   node scripts/screenshot.mjs   writes/refreshes golden-baselines/
// See docs/golden-workflow.md for the full workflow this is part of.

import { chromium } from 'playwright';
import { spawn } from 'node:child_process';
import { mkdir, readFile, writeFile } from 'node:fs/promises';
import { existsSync } from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const ROOT = path.resolve(__dirname, '..');
const BASELINES_DIR = path.join(ROOT, 'golden-baselines');
const ROUTES_FILE = path.join(BASELINES_DIR, 'routes.json');
const PORT = 4322;
const BASE_URL = `http://127.0.0.1:${PORT}`;

const VIEWPORTS = [
  { name: 'mobile', width: 375, height: 812 },
  { name: 'tablet', width: 768, height: 1024 },
  { name: 'desktop', width: 1440, height: 900 },
];

const SCHEMES = ['light', 'dark'];

const slugForRoute = (route) => (route === '/' ? 'home' : route.replace(/^\/|\/$/g, '').replace(/\//g, '-'));

async function waitForServer(url, timeoutMs = 15000) {
  const start = Date.now();
  while (Date.now() - start < timeoutMs) {
    try {
      const res = await fetch(url);
      if (res.status) return;
    } catch {
      // not listening yet
    }
    await new Promise((r) => setTimeout(r, 200));
  }
  throw new Error(`Preview server at ${url} did not come up within ${timeoutMs}ms`);
}

function startPreviewServer() {
  const child = spawn('npx', ['--no-install', 'astro', 'preview', '--port', String(PORT)], {
    cwd: ROOT,
    stdio: ['ignore', 'ignore', 'pipe'],
  });
  let stderr = '';
  child.stderr.on('data', (chunk) => {
    stderr += chunk.toString();
  });
  return { child, getStderr: () => stderr };
}

async function settlePage(page) {
  // Freeze animations/transitions and skip the IntersectionObserver-gated fade-ins
  // (Tailwind's `intersect` variant is `&:not([no-intersect])`, see tailwind.css) so a
  // full-page screenshot doesn't catch below-the-fold sections mid-fade or hidden.
  await page.addStyleTag({
    content: '*, *::before, *::after { animation: none !important; transition: none !important; }',
  });
  await page.evaluate(() => {
    document.querySelectorAll('[class*="intersect"]').forEach((el) => el.setAttribute('no-intersect', ''));
  });
  await page.evaluate(() => document.fonts.ready);
}

async function captureRoute(browser, route) {
  const slug = slugForRoute(route);
  const shots = [];
  for (const scheme of SCHEMES) {
    const context = await browser.newContext({ colorScheme: scheme });
    if (scheme === 'dark') {
      // Matches ApplyColorMode.astro: it reads localStorage.theme, not just the OS
      // color-scheme preference.
      await context.addInitScript(() => localStorage.setItem('theme', 'dark'));
    }
    const page = await context.newPage();
    for (const viewport of VIEWPORTS) {
      await page.setViewportSize({ width: viewport.width, height: viewport.height });
      await page.goto(`${BASE_URL}${route}`, { waitUntil: 'networkidle' });
      await settlePage(page);
      const fileName = `${scheme}-${viewport.name}.png`;
      const buffer = await page.screenshot({ fullPage: true });
      shots.push({ slug, fileName, buffer });
    }
    await context.close();
  }
  return shots;
}

async function writeBaselines(shots) {
  for (const shot of shots) {
    const dir = path.join(BASELINES_DIR, shot.slug);
    await mkdir(dir, { recursive: true });
    await writeFile(path.join(dir, shot.fileName), shot.buffer);
  }
}

async function main() {
  if (!existsSync(path.join(ROOT, 'dist', 'index.html'))) {
    console.error('No ./dist build found. Run "npm run build" first.');
    process.exit(1);
  }
  const routes = JSON.parse(await readFile(ROUTES_FILE, 'utf8'));
  const { child, getStderr } = startPreviewServer();
  let browser;
  try {
    await waitForServer(BASE_URL);
    browser = await chromium.launch();
    const allShots = [];
    for (const route of routes) {
      allShots.push(...(await captureRoute(browser, route)));
    }
    await writeBaselines(allShots);
    console.log(`Wrote ${allShots.length} screenshots to golden-baselines/.`);
  } catch (err) {
    console.error(getStderr());
    throw err;
  } finally {
    if (browser) await browser.close();
    child.kill();
  }
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```

- [ ] **Step 2: Add the check function**

Add this function right after `writeBaselines`:

```js
async function checkAgainstBaselines(shots) {
  let changed = 0;
  await rm(DIFF_DIR, { recursive: true, force: true });
  for (const shot of shots) {
    const baselinePath = path.join(BASELINES_DIR, shot.slug, shot.fileName);
    if (!existsSync(baselinePath)) {
      console.error(`  ! ${shot.slug}/${shot.fileName}: no baseline (run "npm run screenshot" first)`);
      changed++;
      continue;
    }
    const baseline = PNG.sync.read(await readFile(baselinePath));
    const current = PNG.sync.read(shot.buffer);
    if (baseline.width !== current.width || baseline.height !== current.height) {
      console.error(
        `  ! ${shot.slug}/${shot.fileName}: size changed (${baseline.width}x${baseline.height} -> ${current.width}x${current.height})`
      );
      await mkdir(path.join(DIFF_DIR, shot.slug), { recursive: true });
      await writeFile(path.join(DIFF_DIR, shot.slug, shot.fileName), shot.buffer);
      changed++;
      continue;
    }
    const diff = new PNG({ width: baseline.width, height: baseline.height });
    const diffPixels = pixelmatch(baseline.data, current.data, diff.data, baseline.width, baseline.height, {
      threshold: 0.1,
    });
    if (diffPixels > MAX_DIFF_PIXELS) {
      console.error(`  ! ${shot.slug}/${shot.fileName}: ${diffPixels} px differ`);
      await mkdir(path.join(DIFF_DIR, shot.slug), { recursive: true });
      await writeFile(path.join(DIFF_DIR, shot.slug, shot.fileName), PNG.sync.write(diff));
      changed++;
    } else {
      console.log(`  - ${shot.slug}/${shot.fileName}`);
    }
  }
  return changed;
}
```

```markdown
# Golden branch workflow

`golden` is a long-lived branch (added in a later phase) holding a real, built
client site plus a small synthetic fixture, used to catch template-core regressions
visually. This doc covers the screenshot tooling on `main` (`scripts/screenshot.mjs`)
and the workflow for using it once `golden` exists.

## One-time setup

\`\`\`
npm ci
npx playwright install chromium
\`\`\`

## Refreshing the baseline

After a change that's meant to change how pages render:

\`\`\`
npm run build
npm run screenshot
\`\`\`

Writes one PNG per route, per color scheme (light/dark), per viewport (375/768/1440)
into `golden-baselines/`. Commit the result.

## Checking a change against the baseline

\`\`\`
npm run build
npm run screenshot:check
\`\`\`

Exits non-zero if any screenshot differs from `golden-baselines/` by more than a
small pixel tolerance. Diff images go to `golden-baselines-diff/` (gitignored,
inspect locally, never committed, cleared at the start of every check run).

## Testing a template-core change against `golden` (once it exists)

\`\`\`
git checkout golden
git merge main

# resolve any conflicts per the convention below

npm ci && npx playwright install chromium
npm run build
npm run screenshot:check

# inspect golden-baselines-diff/ for anything unexpected;

# if the change is intended, npm run screenshot to refresh baselines and commit on golden

\`\`\`

`golden` never merges back into `main`.

### Merge-conflict convention

`golden` overrides several files that template changes on `main` are also likely to
touch: `src/brand.ts`, `src/navigation.ts`, `src/config.yaml`, `src/schema.ts`. When
`git merge main` conflicts on one of these, take golden's version by default
(`git checkout --ours <file>`), then manually re-apply any new keys or structural
additions `main` introduced (a new config key, a new brand token, a new schema field)
using the conflict markers as the checklist of what to check. Never take `main`'s
version wholesale, that silently reverts the client-layer customization the branch
exists to preserve.

## Routes

The route list lives in `golden-baselines/routes.json`. Update it by hand when pages
are added or removed.
```
